Casos de Uso — Pagos ​

UC-PAY-001: Mostrar métodos de pago por país ​

  • Req cubierto: REQ-PAY-001
  • Dado una organización registrada en "Argentina"
  • Cuando el usuario accede a la pantalla de checkout
  • Entonces solo se muestran métodos de pago habilitados para Argentina
  • Y no aparecen métodos de otros países

UC-PAY-002: Congelar tasa de cambio al crear pago ​

  • Req cubierto: REQ-PAY-002
  • Dado un pago en USD para una organización con moneda local ARS
  • Cuando el usuario confirma el pago
  • Entonces la tasa de cambio ARS/USD se congela en el momento de creación
  • Y si la tasa fluctúa al día siguiente, el registro del pago no se modifica

UC-PAY-003: Factura con régimen fiscal correcto ​

  • Req cubierto: REQ-PAY-003
  • Dado una organización con régimen fiscal "Responsable Inscripto"
  • Cuando se genera una factura por un pago exitoso
  • Entonces la factura muestra los datos fiscales correctos de la organización
  • Y el IVA se calcula según la tasa vigente para ese régimen

UC-PAY-004: Conciliación bancaria ​

  • Req cubierto: REQ-PAY-004
  • Dado un archivo de extracto bancario subido por el usuario
  • Cuando el sistema procesa la conciliación
  • Entonces los pagos coincidentes se marcan como "verificados"
  • Y un pago verificado no puede ser modificado ni eliminado

UC-PAY-005: Notificación de pago recibido ​

  • Req cubierto: REQ-PAY-005
  • Dado un cliente con un turno reservado
  • Cuando el pago del turno es registrado exitosamente
  • Entonces el sistema envía una notificación al cliente
  • Y el turno cambia a estado "confirmado"
