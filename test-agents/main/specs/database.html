Modelo de Base de Datos ​

Requerimientos ​

REQ-DB-001: Diccionario de estados numéricos ​

Todos los estados operativos usan INTEGER referenciando SystemStatusDictionary.

REQ-DB-002: RLS con tenant switching ​

Cada tabla multitenant tiene políticas RLS que usan app.current_tenant_id del JWT.

REQ-DB-003: Campos de auditoría estándar ​

Todas las tablas operativas tienen created_at, updated_at, created_by, updated_by.

REQ-DB-004: Soft delete para clientes y empleados ​

Los registros se inhabilitan, no se eliminan físicamente.

REQ-DB-005: Índices por tenant ​

Toda consulta multitenant debe estar indexada por organization_id.

REQ-DB-006: Privacidad de contactos ​

Los datos de contacto pueden sobreescribirse localmente por el tenant en ClientOrganization.

Políticas RLS ​

sql
CREATE POLICY "Tenant isolation"
ON "Appointment"
FOR ALL
TO authenticated
USING (
  org_id = current_setting('app.current_tenant_id')::uuid
);
