REQ-COL-FILTERABLE — Filterable Columns ​

Requerimiento: El filtro global DEBE buscar solo en columnas donde filterable !== false. Columnas con filterable: false DEBEN ser excluidas. Cuando filterable es undefined, la columna DEBE incluirse por defecto.

TC-COL-FILTERABLE-01: filterable: false excluye columna de búsqueda ​

CampoValor
IDTC-COL-FILTERABLE-01
RequerimientoREQ-COL-FILTERABLE
PrioridadAlta
TipoFuncional — Happy Path
PrecondicionesColumnas: [{key: 'name', header: 'Name'}, {key: 'notes', header: 'Notes', filterable: false}]. Filas: [{name: 'Alice', notes: 'confidential'}].
Pasos1. Escribir "confidential" en el filtro global
2. Verificar filas mostradas
Resultado EsperadoNo se muestran filas. La columna notes fue excluida de la búsqueda, por lo que "confidential" no encontró match.

TC-COL-FILTERABLE-02: filterable: false no oculta datos del UI ​

CampoValor
IDTC-COL-FILTERABLE-02
RequerimientoREQ-COL-FILTERABLE
PrioridadAlta
TipoFuncional — Happy Path
PrecondicionesMisma config que TC-COL-FILTERABLE-01
Pasos1. Escribir "Alice" en el filtro global
2. Verificar filas mostradas
Resultado EsperadoLa fila Alice se muestra porque la columna name (filterable por defecto) contiene "Alice". La columna notes se renderiza visualmente pero no participa en la búsqueda.

TC-COL-FILTERABLE-03: filterable undefined incluye columna por defecto ​

CampoValor
IDTC-COL-FILTERABLE-03
RequerimientoREQ-COL-FILTERABLE
PrioridadAlta
TipoFuncional — Happy Path (borde)
PrecondicionesColumnas sin propiedad filterable (o filterable: undefined). Filas con datos variados.
Pasos1. Escribir un término que exista en cualquier columna
2. Verificar que la fila correspondiente aparece
Resultado EsperadoTodas las columnas participan en el filtro global. La fila con el término buscado aparece.

TC-COL-FILTERABLE-04: Todas las columnas con filterable:false — filtro no encuentra nada ​

CampoValor
IDTC-COL-FILTERABLE-04
RequerimientoREQ-COL-FILTERABLE
PrioridadMedia
TipoFuncional — Edge Case
PrecondicionesTodas las columnas tienen filterable: false
Pasos1. Escribir cualquier término en el filtro global
2. Verificar resultado
Resultado EsperadoEl filtro global no encuentra ninguna fila (no hay columnas searchables). Todas las filas se ocultan independientemente del término.

TC-COL-FILTERABLE-05: Filtro global con mezcla filterable true/false/undefined ​

CampoValor
IDTC-COL-FILTERABLE-05
RequerimientoREQ-COL-FILTERABLE
PrioridadAlta
TipoFuncional — Integración
PrecondicionesColumnas: [{key: 'a'}, {key: 'b', filterable: false}, {key: 'c', filterable: true}]. Filas con datos en a, b, c.
Pasos1. Buscar término que solo existe en columna b (filterable: false)
2. Buscar término que existe en columna a
3. Buscar término que existe en columna c
Resultado Esperado1. Sin resultados (b está excluida)
2. Fila encontrada (a incluida por defecto)
3. Fila encontrada (c tiene filterable: true explícito)
