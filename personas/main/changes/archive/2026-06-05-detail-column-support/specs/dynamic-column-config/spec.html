Delta for dynamic-column-config ​

ADDED Requirements ​

Requirement: Detail Property ​

Columns MAY specify detail: boolean to mark them as carriers of invisible data. A column with detail: true MUST have its row value preserved for emission on cell click, even when visible: false.

Scenario: Detail column carries invisible data on click ​

  • GIVEN a column {key: 'id', header: 'ID', visible: false, detail: true} and a row {name: 'Alice', id: '42'}
  • WHEN a clickable cell in that row is clicked
  • THEN the cellClick payload includes {label: 'ID', value: '42'} in detailData

Scenario: Non-detail invisible column excluded from emission ​

  • GIVEN a column {key: 'secret', header: 'Secret', visible: false} without detail: true
  • WHEN a clickable cell in that row is clicked
  • THEN secret MUST NOT appear in detailData

Requirement: Detail Data Emission ​

When a clickeable cell is clicked, the component MUST collect all columns where detail: true from that row and append them as detailData in the cellClick payload.

Scenario: Multiple detail columns emit all values ​

  • GIVEN columns with key: 'orderId', detail: true and key: 'market', detail: true
  • AND a row {name: 'Alice', orderId: 'ORD-123', market: 'NYSE'}
  • WHEN the user clicks a clickable cell in that row
  • THEN detailData contains two entries with labels "Order ID" and "Market"

Scenario: No detail columns emits empty array ​

  • GIVEN columns without any detail: true
  • WHEN a clickable cell is clicked
  • THEN cellClick.detailData is []

Requirement: Detail Data Format ​

The detailData field SHOULD be an array of {label: string; value: any} objects. label MUST match the column header and value MUST match the row field value.

Scenario: detailData follows label/value contract ​

  • GIVEN a column {key: 'code', header: 'Code', detail: true} and a row with code: 'ABC'
  • WHEN a clickable cell is clicked
  • THEN detailData[0] equals {label: 'Code', value: 'ABC'}

MODIFIED Requirements ​

Requirement: Column Visibility ​

The table MUST exclude columns with visible: false from the rendered DOM. Columns where visible is undefined or true MUST render normally. Columns with detail: true SHOULD also be visible: false — their data is preserved for emission but not rendered. (Previously: No mention of detail columns or data carriage)

Scenario: Column with visible: false is excluded ​

  • GIVEN a table with columns [{key: 'name', header: 'Name'}, {key: 'secret', header: 'Secret', visible: false}]
  • WHEN the table renders
  • THEN only the name column appears in the rendered DOM
  • AND the secret column is absent (not merely hidden via CSS)

Scenario: Column with undefined visible renders ​

  • GIVEN a column with no visible property set
  • WHEN the table renders
  • THEN that column appears in the rendered DOM

Requirement: Clickable Cells ​

When a column has clickeable: true, clicking a cell MUST emit a cellClick event with payload { column: TableColumn; row: any; detailData?: {label: string, value: any}[] }. The component MUST NOT handle the action itself — it delegates to the parent. When detail columns exist, their values are included in detailData. (Previously: Payload was { column; row } without detailData)

Scenario: Clickable cell emits cellClick with detailData ​

  • GIVEN a column {key: 'name', header: 'Name', clickeable: true}
  • AND a detail column {key: 'id', header: 'ID', visible: false, detail: true}
  • AND a row {name: 'Alice', id: '42'}
  • WHEN the user clicks the "Alice" cell
  • THEN cellClick payload includes detailData: [{label: 'ID', value: '42'}]

Scenario: Non-clickable cell emits nothing ​

  • GIVEN a column without clickeable or with clickeable: false
  • WHEN the user clicks a cell in that column
  • THEN no cellClick event is emitted
