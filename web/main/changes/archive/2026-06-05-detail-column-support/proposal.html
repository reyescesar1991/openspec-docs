Proposal: Detail Column Support ​

Intent ​

Enable hidden detail fields in table rows so that clicking a clickable cell emits associated detail data to the parent. The parent then opens a ConfirmationDialog modal with that data, fetched dynamically from the backend.

Scope ​

In Scope ​

  • Extend TableColumn with optional detail, detailFrom properties
  • When a clickeable cell is clicked, collect all detail: true fields from that row and emit them in the cellClick payload
  • Refactor tabla-consulta-ordenes-subasta to call API, build dynamic columns, handle cellClick, and open ConfirmationDialog
  • Add optional date input + search button for executionTime filter
  • Error handling via SweetAlert modal

Out of Scope ​

  • Other tables reusing this detail pattern (deferred to consumer choice)
  • Keyboard navigation or focus management for the detail modal
  • Server-side pagination for the dynamic table

Capabilities ​

New Capabilities ​

None — extending existing capability only.

Modified Capabilities ​

  • dynamic-column-config: add detail (boolean) and detailFrom (string) properties to column configuration. When detail: true, the column carries invisible data (already visible: false). On clickeable cell click, all detail: true fields from that row are collected and emitted as detailData in the cellClick payload.

Approach ​

  1. Interface: Add optional detail?: boolean and detailFrom?: string to TableColumn — backward-compatible
  2. Emission: On cellClick, iterate row fields, collect key-value pairs where detail: true on the matching column, and append detailData: {label, value}[] to the event payload
  3. Parent API: Call getOpenOperationsCurrencyData({ executionTime, market }) on init, map response columns to TableColumn[], render rows
  4. UI: Add optional [(ngModel)] date input + search button in parent template; filter by executionTime on search
  5. Modal: On cellClick, call ConfirmationDialogService.open('title', detailData) without subscribing to afterClosed. On API error, show SweetAlert error modal
