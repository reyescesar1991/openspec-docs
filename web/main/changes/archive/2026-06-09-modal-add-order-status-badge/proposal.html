Proposal: Add Order Status Badge & Order Routing Modal ​

Intent ​

The auction orders table has an unused add button and displays order status as plain text. Users need a modal to route to different order types (Intervención, Mesa de cambio) and visual differentiation of statuses (en proceso, aprobada, rechazada) for quick scanability.

Scope ​

In Scope ​

  • Add (click) handler to the existing add button to open a modal
  • Create ModalCurrencyAddOrderComponent in src/app/features/shared/
  • Material select with routing: Intervención → main/divisas/compra/intervencion, Mesa de cambio - Compra → main/divisas/compra/mesa-cambio, Mesa de cambio - Venta → main/divisas/venta/mesa-cambio
  • Status column visual badge (en proceso, aprobada, rechazada) using CSS variables from styles.scss
  • Register modal in SharedModule; add to DivisasModule if needed

Out of Scope ​

  • Backend changes to status field values or structure
  • Sorting/filtering changes to the generic table
  • Visual changes to other table columns

Capabilities ​

New Capabilities ​

  • order-routing-modal: Modal dialog for selecting and navigating to order creation pages
  • order-status-badge: Visual chip/badge component for auction order status display

Modified Capabilities ​

  • None

Approach ​

  1. Add button: Bind (click)="openAddModal()" to existing <button mat-mini-fab> in the HTML template; implement openAddModal() in the component TS to call MatDialog.open(ModalCurrencyAddOrderComponent).

  2. Modal: Create src/app/features/shared/modal-currency-add-order/ with Angular Material MatDialog. SVG close button using --color-principal + hover lift animation. Label + <mat-select> with 3 options. On selection, this.router.navigate(['main/divisas/...']) then close dialog.

  3. Status badge: Custom CSS classes bound to the status value (using [ngClass] or a custom pipe). Map: "en proceso" → amber/warning (--card-color: #7ab400), "aprobada" → green success (--color-principal: #62A730), "rechazada" → red (--color-rojo: #f83a40). Apply as small rounded chips.

  • Angular Material Dialog (MatDialog) already imported
  • RouterModule available in DivisasModule context

Success Criteria ​

  • [ ] Clicking add button opens the modal with correct label and select options
  • [ ] Each select option navigates to the correct route and closes the modal
  • [ ] Status column shows colored badges (green/orange/red) instead of plain text
  • [ ] All styles use CSS variables from styles.scss, no hardcoded colors
