Design: Modal de Agregar Orden + Status Badge en Tabla ​

Technical Approach ​

Two independent changes under one change name: (A) new ModalCurrencyAddOrderComponent in shared module for order-type selection with routing, and (B) add configurable badge rendering to GenericTableWithoutActionsComponent for visual status indicators. Both follow existing project patterns — MatDialog modals, SharedModule registration, and scoped SCSS with CSS variables.

Architecture Decisions ​

DecisionOptionsTradeoffsChosen
Modal locationShared vs divisas-localShared: reusable but adds import; Local: no cross-module coupling but duplicate if reusedShared (follows existing modal pattern like modal-actions-account)
Badge triggerNew TableColumn.type field vs hardcoded key === 'status'Interface field: extensible, explicit contract; Key check: fragile, couples to backend field nametype?: 'badge' on TableColumn
Status color mappingPipe vs [ngClass] method vs component mapPipe: pure, testable but one-off; ngClass method: inline, simple; Map: configurableCSS classes via [ngClass] + static status-to-class map
Modal routingAbsolute vs relative navigationAbsolute: works from any context; Relative: couples to current route depthAbsolute ['main/divisas/...'] — stable path per module hierarchy

Data Flow ​

Modal Flow ​

Add btn click (template)
  → openDialog(ModalCurrencyAddOrderComponent)  [TablaConsultaOrdenesSubastaComponent]
    → user selects option in <mat-select>
      → (selectionChange) handler maps value → route
        → this.router.navigate([route]) + dialogRef.close()

Badge Flow ​

API response → column config rows
  → TablaConsultaOrdenesSubasta maps status column → { ..., type: 'badge' }
  → GenericTableWithoutActions renders <td>
    → column.type === 'badge'  →  <span class="status-badge status-{value}">
    → ngClass maps status string to CSS class
      → class drives background-color via CSS variable

Migration / Rollout ​

No migration required. Both additions are opt-in — existing columns without type: 'badge' render as plain text; the modal has no impact until the add button click event is wired.
