Proposal: Generic Table Column Enhancement ​

Intent ​

TableColumn currently only carries key + header. The GenericTableWithoutActionsComponent iterates all columns with no conditional rendering, no click handling, and a global filter that searches every column. We need backend-driven column configuration: visibility, tooltips, click actions, and filterable control — without breaking existing usage.

Scope ​

In Scope ​

  • Extend TableColumn interface with visible, tooltip, clickeable, filterable
  • Filter displayedColumns by visible (backward-compatible: default true)
  • Render matTooltip on cells when tooltip is set
  • Emit cellClick event on click when clickeable is true; delegate action to parent
  • Custom filterPredicate on MatTableDataSource to search only filterable columns
  • Import MatTooltipModule where needed

Out of Scope ​

  • Other table components or existing functionality
  • Tests (user disabled Strict TDD)
  • Column reordering, resizing, or sorting
  • New filter UI (reuses existing global search input)
  • Column grouping or aggregation

Capabilities ​

New Capabilities ​

  • dynamic-column-config: Column-level properties (visible, tooltip, clickeable, filterable) that control rendering, interaction, and filter behavior

Modified Capabilities ​

  • None — no existing specs in openspec/specs/

Approach ​

  1. Interface — Add 4 optional booleans + optional string to TableColumn
  2. displayedColumns — Filter by visible in ngOnChanges; skip non-visible column keys
  3. Filter — Set dataSource.filterPredicate to iterate only columns where filterable !== false; apply existing filter.trim().toLowerCase() match on cell values
  4. Template — Conditionally add [matTooltip], (click), and [style.cursor] based on column config
  5. Output — Add @Output() cellClick = new EventEmitter<{ column: TableColumn; row: any }>(); parent handles navigation/modal
  6. Module — Verify MatTooltipModule is imported in the parent module

Rollback Plan ​

git revert <merge-commit> to undo the entire change. If partial rollback needed, restore the 3 affected files from git checkout HEAD~1 -- <file>.

Dependencies ​

  • @angular/material MatTooltipModule (already in project)

Success Criteria ​

  • [ ] TableColumn has the 4 new properties; existing interfaces compile without changes
  • [ ] Columns with visible: false are absent from the rendered table
  • [ ] Clickable cells emit { column, row } on click; parent receives the event
  • [ ] Tooltip columns show matTooltip on cell hover
  • [ ] Global filter matches only filterable: true columns (or all when undefined)
  • [ ] Existing table instances render identically with no errors
