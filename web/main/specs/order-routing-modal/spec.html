Order Routing Modal Specification ​

Purpose ​

Modal component for selecting order creation type and routing the user to the corresponding order form page.

Requirements ​

Requirement: Modal Trigger ​

The parent component MUST open a MatDialog with ModalCurrencyAddOrderComponent when the add button is clicked.

Scenario: Add button opens modal ​

  • GIVEN the auction orders table is displayed
  • WHEN the user clicks the add button (mat-mini-fab)
  • THEN a MatDialog modal opens with ModalCurrencyAddOrderComponent

Requirement: Order Type Selection ​

The modal MUST display a label "Seleccione el tipo de orden que desea agregar:" and a <mat-select> with exactly three options: Intervención, Mesa de cambio - Compra, Mesa de cambio - Venta.

Scenario: Label and select are visible ​

  • GIVEN the modal is open
  • WHEN the user views the modal content
  • THEN a descriptive label and a Material select with three order type options are displayed

Requirement: Route Navigation ​

On option selection, the modal MUST navigate to the corresponding route and close itself.

OptionRoute
Intervenciónmain/divisas/compra/intervencion
Mesa de cambio - Compramain/divisas/compra/mesa-cambio
Mesa de cambio - Ventamain/divisas/venta/mesa-cambio

Scenario: Selection navigates and closes ​

  • GIVEN the modal is open with the select
  • WHEN the user selects any option
  • THEN this.router.navigate([route]) is called with the mapped route
  • AND the dialog closes

Requirement: Close Button ​

The modal MUST include an SVG close button (X icon) using --color-principal for the icon color. The close button SHOULD display a hover lift animation.

Scenario: Close button dismisses modal ​

  • GIVEN the modal is open
  • WHEN the user clicks the SVG close button
  • THEN the dialog closes

Requirement: Visual Consistency ​

The modal MUST use CSS variables from styles.scss for all colors. No hardcoded hex or RGB values. The design MUST be minimal and visually coherent with the system theme.

Scenario: Style compliance ​

  • GIVEN the modal is rendered
  • THEN all color values reference CSS variables from styles.scss
