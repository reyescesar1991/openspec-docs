Order Status Badge Specification ​

Purpose ​

Visual chip/badge component that renders auction order status values as colored indicators in the table, replacing plain text for quick scanability.

Requirements ​

Requirement: Status Badge Rendering ​

The generic-table-without-actions component MUST render the status column value as a visual badge/chip element instead of plain text.

Scenario: Status renders as chip ​

  • GIVEN the table displays order rows with a status column
  • THEN each status cell renders as a small rounded chip with a background color

Requirement: Status Color Mapping ​

The badge color MUST vary by status value using only CSS variables from styles.scss:

StatusColorCSS Variable
en procesoAmber/green--card-color: #7ab400
aprobadaGreen--color-principal: #62A730
rechazadaRed--color-rojo: #f83a40

Scenario: "en proceso" renders amber chip ​

  • GIVEN a row with status = "en proceso"
  • WHEN the table renders
  • THEN the status cell shows an amber-colored badge using var(--card-color)

Scenario: "aprobada" renders green chip ​

  • GIVEN a row with status = "aprobada"
  • WHEN the table renders
  • THEN the status cell shows a green-colored badge using var(--color-principal)

Scenario: "rechazada" renders red chip ​

  • GIVEN a row with status = "rechazada"
  • WHEN the table renders
  • THEN the status cell shows a red-colored badge using var(--color-rojo)

Requirement: No Hardcoded Colors ​

All status badge colors MUST reference CSS variables from styles.scss. Hardcoded color values MUST NOT be used.

Scenario: CSS variable compliance ​

  • GIVEN any status badge is rendered
  • THEN its background color uses var(--card-color), var(--color-principal), or var(--color-rojo)
  • AND no hardcoded hex or RGB values are present

Requirement: Dynamic Class Binding ​

The badge class MUST be dynamically bound to the row's status value using [ngClass] or equivalent Angular template binding.

Scenario: Unknown status fallback ​

  • GIVEN a row with an unrecognized status value
  • WHEN the table renders
  • THEN the status cell renders with a neutral/default style
  • AND no error or exception is thrown
