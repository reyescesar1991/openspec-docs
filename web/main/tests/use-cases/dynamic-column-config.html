Use Cases — dynamic-column-config ​

Generado a partir de openspec/specs/dynamic-column-config/spec.md

UC-COL-VISIBILITY-01: Columna oculta no se renderiza ​

Requirement: REQ-COL-VISIBILITY — Column Visibility

Dado una tabla con columnas [{key: 'name', header: 'Name'}, {key: 'secret', header: 'Secret', visible: false}]Cuando la tabla se renderiza Entonces solo la columna name aparece en el DOM renderizado Y la columna secret está ausente del DOM (no meramente oculta via CSS)

UC-COL-VISIBILITY-02: Columna sin visible se renderiza normalmente ​

Requirement: REQ-COL-VISIBILITY — Column Visibility

Dado una columna sin propiedad visibleCuando la tabla se renderiza Entonces esa columna aparece en el DOM renderizado

UC-COL-TOOLTIP-01: Tooltip aparece al hacer hover ​

Requirement: REQ-COL-TOOLTIP — Cell Tooltip

Dado una columna {key: 'email', header: 'Email', tooltip: 'Click to copy'}Cuando el usuario hace hover sobre una celda de esa columna Entonces aparece un tooltip de Material con el texto "Click to copy"

UC-COL-TOOLTIP-02: Columna sin tooltip no muestra tooltip ​

Requirement: REQ-COL-TOOLTIP — Cell Tooltip

Dado una columna sin propiedad tooltipCuando el usuario hace hover sobre una celda de esa columna Entonces no aparece ningún tooltip

UC-COL-CLICKABLE-01: Celda clickeable emite cellClick con detailData ​

Requirement: REQ-COL-CLICKABLE — Clickable Cells

Dado una columna {key: 'name', header: 'Name', clickeable: true}Y una columna de detalle {key: 'id', header: 'ID', visible: false, detail: true}Y una fila {name: 'Alice', id: '42'}Cuando el usuario hace clic en la celda "Alice" Entonces el payload de cellClick incluye detailData: [{label: 'ID', value: '42'}]

UC-COL-CLICKABLE-02: Celda no clickeable no emite evento ​

Requirement: REQ-COL-CLICKABLE — Clickable Cells

Dado una columna sin clickeable o con clickeable: falseCuando el usuario hace clic en una celda de esa columna Entonces no se emite ningún evento cellClick

UC-COL-FILTERABLE-01: Filtro global excluye columna con filterable: false ​

Requirement: REQ-COL-FILTERABLE — Filterable Columns

Dado columnas [{key: 'name', header: 'Name'}, {key: 'notes', header: 'Notes', filterable: false}]Y filas [{name: 'Alice', notes: 'confidential'}]Cuando el usuario escribe "confidential" en el filtro global Entonces no se muestran filas (la columna notes fue excluida de la búsqueda)

UC-COL-FILTERABLE-02: Filtro global incluye columna sin filterable ​

Requirement: REQ-COL-FILTERABLE — Filterable Columns

Dado columnas sin propiedad filterableCuando el usuario escribe un término en el filtro global Entonces todas las columnas son buscadas (compatibilidad hacia atrás)

UC-BACKWARD-COMPAT-01: Configuración legacy funciona idénticamente ​

Requirement: REQ-BACKWARD-COMPAT — Backward Compatibility

Dado un componente de tabla con un array legacy de columnas [{key: 'name', header: 'Name'}]Cuando el componente se inicializa Entonces todas las columnas se renderizan normalmente Y no aparecen tooltips al hacer hover sobre celdas Y hacer clic en celdas no tiene efecto Y el filtro global busca en todas las columnas

UC-DETAIL-PROP-01: Columna detail preserva dato invisible en click ​

Requirement: REQ-DETAIL-PROP — Detail Property

Dado una columna {key: 'id', header: 'ID', visible: false, detail: true}Y una fila {name: 'Alice', id: '42'}Cuando se hace clic en una celda clickeable de esa fila Entonces el payload cellClick incluye {label: 'ID', value: '42'} en detailData

UC-DETAIL-PROP-02: Columna invisible sin detail queda excluida de emisión ​

Requirement: REQ-DETAIL-PROP — Detail Property

Dado una columna {key: 'secret', header: 'Secret', visible: false} sin detail: trueCuando se hace clic en una celda clickeable de esa fila Entonces secret NO aparece en detailData

UC-DETAIL-EMISSION-01: Múltiples columnas detail emiten todos los valores ​

Requirement: REQ-DETAIL-EMISSION — Detail Data Emission

Dado columnas con key: 'orderId', detail: true y key: 'market', detail: trueY una fila {name: 'Alice', orderId: 'ORD-123', market: 'NYSE'}Cuando el usuario hace clic en una celda clickeable de esa fila Entonces detailData contiene dos entradas con labels "Order ID" y "Market"

UC-DETAIL-EMISSION-02: Sin columnas detail emite array vacío ​

Requirement: REQ-DETAIL-EMISSION — Detail Data Emission

Dado columnas sin ninguna con detail: trueCuando se hace clic en una celda clickeable Entonces cellClick.detailData es []

UC-DETAIL-FORMAT-01: detailData sigue el contrato label/value ​

Requirement: REQ-DETAIL-FORMAT — Detail Data Format

Dado una columna {key: 'code', header: 'Code', detail: true}Y una fila con code: 'ABC'Cuando se hace clic en una celda clickeable Entonces detailData[0] es igual a {label: 'Code', value: 'ABC'}
