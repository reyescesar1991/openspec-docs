REQ-COL-VISIBILITY — Column Visibility ​

Requerimiento: La tabla DEBE excluir columnas con visible: false del DOM renderizado. Columnas con visible: undefined o true DEBEN renderizarse normalmente.

TC-COL-VISIBILITY-01: Columna con visible: false se excluye del DOM ​

CampoValor
IDTC-COL-VISIBILITY-01
RequerimientoREQ-COL-VISIBILITY
PrioridadAlta
TipoFuncional — Happy Path
PrecondicionesComponente GenericTableWithoutActionsComponent inicializado con columnas: [{key: 'name', header: 'Name'}, {key: 'secret', header: 'Secret', visible: false}] y al menos una fila de datos
Pasos1. Configurar tabla con columnas mixtas (visible y visible:false)
2. Renderizar el componente
3. Inspeccionar el DOM renderizado
Resultado EsperadoLa columna name aparece en el DOM. La columna secret NO aparece en el DOM (no debe estar ni siquiera con display:none).
NotasVerificar con querySelector que no exista ningún elemento con clave secret en el encabezado ni en las celdas.

TC-COL-VISIBILITY-03: Columna sin visible (undefined) se renderiza ​

TC-COL-VISIBILITY-04: Todas las columnas con visible:false — tabla vacía ​

CampoValor
IDTC-COL-VISIBILITY-04
RequerimientoREQ-COL-VISIBILITY
PrioridadMedia
TipoFuncional — Edge Case
PrecondicionesTodas las columnas tienen visible: false
Pasos1. Configurar tabla solo con columnas ocultas
2. Renderizar
