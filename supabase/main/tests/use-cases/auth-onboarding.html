Auth & Onboarding — Use Cases ​

UC-AUTH-001: Login exitoso con email y contraseña ​

  • Screen: Login
  • Dado un usuario registrado con email válido y contraseña correcta
  • Cuando el usuario ingresa sus credenciales y presiona "Iniciar sesión"
  • Entonces el sistema valida las credenciales contra Supabase Auth
  • Y redirige al dashboard correspondiente al rol del usuario
  • Y almacena el JWT en localStorage

UC-AUTH-002: Login con email inexistente ​

  • Screen: Login
  • Dado un email que no está registrado en el sistema
  • Cuando el usuario intenta iniciar sesión con ese email
  • Entonces el sistema muestra "Credenciales inválidas"
  • Y no se crea ninguna sesión

UC-AUTH-003: Login con contraseña incorrecta ​

  • Screen: Login
  • Dado un usuario registrado con email válido
  • Cuando el usuario ingresa una contraseña incorrecta
  • Entonces el sistema muestra "Credenciales inválidas"
  • Y registra el intento fallido

UC-AUTH-004: Registro exitoso de nuevo usuario ​

  • Screen: Sign Up
  • Dado un usuario no registrado con email y datos válidos
  • Cuando el usuario completa el formulario de registro
  • Entonces el sistema crea la cuenta en Supabase Auth
  • Y redirige al Organization Onboarding Wizard

UC-AUTH-005: Registro con email duplicado ​

  • Screen: Sign Up
  • Dado un email que ya está registrado en el sistema
  • Cuando el usuario intenta registrarse con ese email
  • Entonces el sistema muestra "El email ya está registrado"
  • Y no crea la cuenta

UC-AUTH-006: Completar wizard de onboarding ​

  • Screen: Organization Onboarding Wizard
  • Dado un usuario que acaba de registrarse
  • Cuando el usuario completa todos los pasos del wizard
  • Entonces el sistema crea la organización con los datos provistos
  • Y redirige al dashboard de la organización

UC-AUTH-007: Cancelar wizard de onboarding ​

  • Screen: Organization Onboarding Wizard
  • Dado un usuario en medio del wizard de onboarding
  • Cuando el usuario cancela el proceso
  • Entonces el sistema no crea ninguna organización
  • Y redirige a la pantalla de Sign Up

UC-AUTH-008: Cambiar de tenant exitosamente ​

  • Screen: Tenant Switcher
  • Dado un usuario con acceso a múltiples organizaciones
  • Cuando el usuario selecciona otra organización del selector
  • Entonces el sistema cambia el contexto de tenant
  • Y recarga el dashboard con los datos de la nueva organización

UC-AUTH-009: Tenant Switcher sin organizaciones disponibles ​

  • Screen: Tenant Switcher
  • Dado un usuario que pertenece a una sola organización
  • Cuando el usuario abre el Tenant Switcher
  • Entonces el sistema oculta el selector o lo muestra deshabilitado
