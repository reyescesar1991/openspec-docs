System Configuration — Use Cases ​

UC-SYS-001: Visualizar tipos de cambio exitosamente ​

  • Screen: System Exchange Rates
  • Dado que existen tipos de cambio cargados por el bot del backend
  • Cuando el usuario navega a la pantalla de tipos de cambio
  • Entonces el sistema muestra la lista de tipos de cambio disponibles
  • Y cada tasa se congela al momento de la transacción

UC-SYS-002: Tipos de cambio sin datos ​

  • Screen: System Exchange Rates
  • Dado que el bot del backend aún no ha cargado tipos de cambio
  • Cuando el usuario navega a la pantalla de tipos de cambio
  • Entonces el sistema muestra un mensaje "Sin datos disponibles"
  • Y sugiere reintentar más tarde

UC-SYS-003: Crear nuevo tipo de documento ​

  • Screen: Document Types
  • Dado un usuario con permisos de administración
  • Cuando el usuario crea un nuevo tipo de documento con datos válidos
  • Entonces el sistema guarda el tipo de documento
  • Y lo muestra en la lista de tipos disponibles

UC-SYS-004: Eliminar tipo de documento en uso ​

  • Screen: Document Types
  • Dado un tipo de documento que está siendo usado por transacciones existentes
  • Cuando el usuario intenta eliminarlo
  • Entonces el sistema bloquea la eliminación
  • Y muestra "No se puede eliminar: el tipo de documento está en uso"

UC-SYS-005: Configurar método de pago exitosamente ​

  • Screen: System Payment Methods
  • Dado un usuario con permisos de configuración
  • Cuando el usuario agrega un nuevo método de pago con datos válidos
  • Entonces el sistema registra el método de pago
  • Y lo activa para uso en transacciones

UC-SYS-006: Desactivar método de pago ​

  • Screen: System Payment Methods
  • Dado un método de pago activo
  • Cuando el usuario lo desactiva
  • Entonces el sistema cambia su estado a inactivo
  • Y las transacciones futuras no podrán usar ese método

UC-SYS-007: Crear plan exitosamente ​

  • Screen: Plan Management
  • Dado un usuario administrador
  • Cuando el usuario crea un nuevo plan con nombre, precio y recursos
  • Entonces el sistema guarda el plan
  • Y queda disponible para asignación

UC-SYS-008: Eliminar plan con organizaciones activas ​

  • Screen: Plan Management
  • Dado un plan que tiene organizaciones activas asignadas
  • Cuando el usuario intenta eliminar el plan
  • Entonces el sistema bloquea la eliminación
  • Y sugiere reasignar las organizaciones primero

UC-SYS-009: Asignar menú a plan exitosamente ​

  • Screen: Plan-Menu Assignment
  • Dado un plan existente y un menú disponible
  • Cuando el usuario asigna el menú al plan
  • Entonces el sistema registra la asignación
  • Y los usuarios del plan ven el nuevo menú

UC-SYS-010: Desasignar menú de plan ​

  • Screen: Plan-Menu Assignment
  • Dado un menú asignado a un plan
  • Cuando el usuario desasigna el menú del plan
  • Entonces el sistema elimina la asignación
  • Y los usuarios del plan dejan de ver ese menú
